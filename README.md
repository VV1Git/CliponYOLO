## Overview

This project explores using computer vision for automated trash detection to help address environmental pollution. It utilizes the **YOLOvX** object detection model to identify various types of litter in images or video streams.

**(Important Note:** Please replace `YOLOvX` above and below with the *specific* YOLO version you used, e.g., `YOLOv8`, `YOLOv9`. As of May 2025, `YOLOv11` is not a standard official release.)**

## Dataset

The model was trained on a dataset comprising >10,000 images containing trash classes such as `[plastic_bottle, can, cardboard, etc.]`. The data was sourced from >10 litter collection cleanup projects done using the proprietary hardware and annotated using LabelMe.

## Technology Stack

* **Python** [3.9+]
* **Object Detection:** Ultralytics YOLOv11
* **Core Libraries:** PyTorch / TensorFlow, OpenCV, NumPy
